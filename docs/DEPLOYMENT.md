# تشغيل النظام على سيرفر الشركة

## المتطلبات
- سيرفر Linux (Ubuntu 22.04 أو أحدث) بذاكرة 4GB على الأقل ومساحة 40GB.
- Docker مع Docker Compose v2.
- للوصول من الإنترنت: اسم نطاق (مثل `erp.alobaidi-cars.com`) يشير إلى عنوان السيرفر، والمنفذان 80 و443 مفتوحان.
- لأجهزة البصمة: المنفذ 8081 مفتوح لشبكات الفروع فقط.

## التثبيت أول مرة
```bash
git clone <رابط المستودع> laith-erp
cd laith-erp/deploy
./install.sh
```
السكربت يسأل عن النطاق وبريد المدير واسمه، ثم:
- يولّد كل كلمات السر والمفاتيح في `deploy/.env` بصلاحية 600.
- يطبع كلمة سر المدير مرة واحدة. غيّرها بعد أول دخول.
- يبني ويشغّل: قاعدة البيانات، الخادم، الواجهة، Caddy (شهادة HTTPS تلقائية)، والنسخ الاحتياطي.

> **مهم جداً:** احفظ نسخة من `deploy/.env` خارج السيرفر. فقدان `DATA_ENCRYPTION_KEY` يعني فقدان أرقام الهويات والحسابات المصرفية المشفرة.

### سيرفر داخلي بدون نطاق
ضع عنوان السيرفر في `ERP_DOMAIN` (مثل `192.168.1.20`)، وفي `deploy/Caddyfile` غيّر السطر الأول من الكتلة إلى `http://{$ERP_DOMAIN}`.

## على Hostinger VPS (الطريقة المعتمدة)
1. من hPanel اشترِ **VPS** (خطة KVM 1 أو KVM 2 تكفي لـ 160 موظف) واختر نظام **Ubuntu 24.04**.
2. من صفحة السيرفر خذ: عنوان IP، واسم السيرفر (مثل `srv123456.hstgr.cloud`)، وكلمة سر root.
3. ادخل على السيرفر من **Browser terminal** في hPanel (أو SSH) ونفّذ:
```bash
git clone https://github.com/hrharlow88-dotcom/Aws-Firas---laith-Al-Obaidi-ERP.git laith-erp
cd laith-erp/deploy
sudo ADMIN_EMAIL=aws.firas@alobaidi-cars.com ADMIN_NAME="أوس فراس" ./install.sh
```
السكربت ينصّب Docker ويفتح المنافذ (22، 80، 443، 8081) ويستخدم اسم السيرفر للشهادة تلقائياً، ثم يطبع كلمة سر المدير.
4. افتح `https://srv123456.hstgr.cloud` (اسم سيرفرك) وسجّل الدخول.

## المدخل من نظام الأوصاف (alobaidi-hr.github.io/erp)
صفحة `https://alobaidi-hr.github.io/erp/` في مستودع نظام الأوصاف تحوّل إلى الـ ERP. بعد التنصيب ضع عنوان السيرفر في ملف `erp/config.js` بذلك المستودع:
```js
window.LO_ERP = { url: 'https://srv123456.hstgr.cloud' };
```
وقبلها تعرض الصفحة أن النظام قيد التنصيب. داخل الـ ERP يفتح تطبيق «الأوصاف الوظيفية» نظام الأوصاف.

### إذا صار عندكم دومين خاص لاحقاً
أضف سجل **A** (مثل `erp`) يشير إلى IP السيرفر، ثم غيّر `ERP_DOMAIN` في `deploy/.env` وأعد التشغيل:
```bash
cd laith-erp/deploy && docker compose -f docker-compose.prod.yml up -d
```

## تحميل بيانات الشركة
ملفات Excel (ملفات رواتب الفروع، السجل الرئيسي، نظام الإجازات) لا تُرفع للمستودع أبداً.
```bash
cp *.xlsx deploy/company-data/
docker compose -f docker-compose.prod.yml exec api node dist/db/importCompany.js /import
```
- الأداة تقرأ شهر الرواتب من لوحة كل ملف، وتحمّل:
  - الفروع، والأقسام والشُعب، والمسميات.
  - الموظفين، والرواتب وراتب منصة الضمان، والمدير المباشر.
  - أيام الاستحقاق والغياب، والعمولات والاستقطاعات، والسلف، وأرصدة الإجازات.
- إعادة التشغيل تحدّث البيانات ولا تكررها. السلف الموجودة لا تُستبدل، لأن تصحيحها يتم من شاشة السلف.
- بعد التحميل احذف الملفات من `company-data`.

## قوالب العقود
من **الموظفون ← قوالب العقود** ارفع ملف Word فيه حقول مثل `{{اسم_الموظف}}` و`{{الراتب}}`، وقائمة الحقول موجودة في نفس الشاشة. بعدها من ملف أي موظف ← **العقود** ← **إنشاء عقد من قالب**.

## الأوصاف الوظيفية ومؤشرات الأداء
1. في نظام الأوصاف: «الإعدادات ← الربط مع الـ ERP» ← تصدير الملف (`lo-hr.jd-kpi`).
2. في الـ ERP: تطبيق «الأداء» ← «استيراد من البوابة» ← معاينة ثم تأكيد. المسميات الناقصة تُنشأ برمز الوظيفة (مثل LO-CRM-01).
3. اربط الموظفين بالوظائف من «الأقسام والهيكل ← استيراد من Excel» بكتابة رمز الوظيفة في عمود المسمى.

## أجهزة البصمة (ZKTeco)
في إعدادات الجهاز (Cloud Server / ADMS):
- عنوان السيرفر: عنوان السيرفر.
- المنفذ: 8081.

ثم أضف عنوان IP الخاص بالفرع في إعدادات الحضور داخل النظام.

## التحديث
```bash
cd laith-erp/deploy && sudo ./update.sh
```
يأخذ نسخة احتياطية من قاعدة البيانات أولاً، ثم يسحب آخر نسخة ويعيد البناء والتشغيل.
تغييرات قاعدة البيانات تُطبق تلقائياً عند التشغيل.

## النسخ الاحتياطي والاسترجاع
- كل ليلة الساعة 2 تُحفظ نسخة من قاعدة البيانات والمستمسكات في `deploy/backups`، وتُحذف النسخ الأقدم من 14 يوماً.
- انسخ هذا المجلد دورياً إلى قرص أو جهاز آخر.

للاسترجاع:
```bash
docker compose -f docker-compose.prod.yml exec -T database pg_restore -U laith_erp_app -d laith_erp --clean < backups/db_YYYY-MM-DD_HHMM.dump
docker compose -f docker-compose.prod.yml run --rm -v "$PWD/backups:/b" --entrypoint sh api -c "tar -xzf /b/uploads_YYYY-MM-DD_HHMM.tar.gz -C /data"
```

## الربط مع SAP Business One
املأ متغيرات `SAP_B1_*` في `deploy/.env` ثم أعد التشغيل. جرّب أولاً على شركة اختبار في SAP قبل الشركة الفعلية.

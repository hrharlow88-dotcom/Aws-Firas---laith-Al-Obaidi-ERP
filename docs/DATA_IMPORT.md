# استيراد بيانات الموارد البشرية

## الحالة الحالية

تتيح النسخة الحالية إدخال الفروع والموظفين يدوياً وحفظهما في PostgreSQL. لا يوجد حالياً استيراد XLSX/CSV أو معالجة عقود أو رواتب، ولم تُحمّل ملفات الموظفين أو الرواتب المرفقة إلى النظام.

تدعم وحدة الإجازات الطلبات والموافقات متعددة الخطوات ودفتر الأرصدة. لا تُرحّل أرصدة Excel تلقائياً، ولا ينشئ حقل الاستحقاق السنوي استحقاقات دورية آلية؛ يلزم إدخال رصيد افتتاحي موثق أو تسوية معتمدة لكل موظف ونوع إجازة. يلزم اعتماد سياسة الإجازات أولاً؛ مراجع العمل تعرض معدلات سنوية متعارضة وتحتاج مراجعة قانونية وإدارية.

## قبل الترحيل

تتضمن ملفات الموارد البشرية والرواتب بيانات شخصية ومالية. قبل إعداد مستورد الإنتاج، ينبغي اعتماد:

- ملف مصدر نهائي لكل فرع والفترة التي ستُرحّل.
- مطابقة أسماء الأعمدة لكل ورقة، وتحديد مصدر الحقيقة عند تكرار السجلات.
- الأدوار المخوّلة باستعراض الرواتب والعقود.
- قواعد العمل المعتمدة للدوام والإجازات والراتب والعملة.
- تقرير معاينة يبيّن عدد الصفوف الصحيحة والمتعارضة قبل اعتماد أي استيراد.

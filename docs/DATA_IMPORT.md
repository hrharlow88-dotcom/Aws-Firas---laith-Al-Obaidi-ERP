# استيراد بيانات الموارد البشرية

## الحالة الحالية

النسخة الأولى تتيح إدخال الفروع والموظفين يدوياً وحفظهما في PostgreSQL. لا يوجد حالياً استيراد XLSX/CSV أو معالجة عقود أو رواتب، ولم تُحمّل ملفات الموظفين المرفقة إلى النظام.

مركز إعدادات المدير يتيح تعريف أنواع الإجازات وخطوات الموافقة، لكن هذه التعريفات لا تنشئ طلبات أو تحتسب أرصدة بعد. لا تُرحّل أرصدة Excel تلقائياً. يلزم اعتماد سياسة الإجازات أولاً؛ مراجع العمل تعرض معدلات سنوية متعارضة وتحتاج مراجعة قانونية وإدارية.

## قبل الترحيل

تتضمن ملفات الموارد البشرية والرواتب بيانات شخصية ومالية. قبل إعداد مستورد الإنتاج، ينبغي اعتماد:

- ملف مصدر نهائي لكل فرع والفترة التي ستُرحّل.
- مطابقة أسماء الأعمدة لكل ورقة، وتحديد مصدر الحقيقة عند تكرار السجلات.
- الأدوار المخوّلة باستعراض الرواتب والعقود.
- قواعد العمل المعتمدة للدوام والإجازات والراتب والعملة.
- تقرير معاينة يبيّن عدد الصفوف الصحيحة والمتعارضة قبل اعتماد أي استيراد.

# مجموعة ليث العبيدي للسيارات — نظام الإدارة

نظام ويب عربي باتجاه RTL. التنفيذ الحالي يغطي تسجيل الدخول والأدوار والفروع ودليل الموظفين، إضافة إلى إدارة أساسية لطلبات الإجازات والموافقات والأرصدة. تبقى الرواتب والمحاسبة والحضور وعمليات السيارات مراحل مستقلة غير منفذة.

## التشغيل المحلي باستخدام Docker

1. انسخ `.env.example` إلى `.env`.
2. حدّث `ADMIN_EMAIL` إلى بريد مسؤول الشركة، وغيّر `DB_PASSWORD` و`JWT_SECRET` و`ADMIN_PASSWORD` إلى قيم عشوائية خاصة بك. يجب أن تكون كلمة مرور المدير 12 محرفاً على الأقل وسر JWT 32 محرفاً على الأقل.
3. شغّل `docker compose up --build`.
4. افتح `http://localhost:3000` وسجّل الدخول بالبريد وكلمة المرور اللذين وضعتَهما في `.env`.

تنشأ قاعدة PostgreSQL دائمة في مجلد Docker volume. لا تستخدم بيانات `.env.example` كما هي، ولا تعرض الخدمة على الإنترنت دون TLS ونسخ احتياطي مُدار وتغيير بيانات الدخول الافتراضية.

## وحدات المرحلة الأولى

- **نظرة عامة:** أعداد الموظفين والفروع النشطة مع أحدث سجلات التعيين.
- **الفروع:** إضافة موقع برمز فريد وربط الموظفين به.
- **الموظفون:** البحث والإضافة وتحديث حالة العمل.
- **المستخدمون والصلاحيات:** حسابات منفصلة بأدوار مدير النظام، الموارد البشرية، المالية، مدير الفرع، والمشاهدة فقط.
- **ضوابط الوصول:** يتحقق الخادم من كل طلب؛ مدير الفرع محصور بفرعه، وبيانات الرواتب غير موجودة في هذه المرحلة.
- **أمان الحساب:** كلمات المرور مشفّرة بـ bcrypt، الجلسات قصيرة الأجل وقابلة للإبطال عند تغيير كلمة المرور أو تعطيل الحساب، مع سجل تدقيق للعمليات الحساسة.
- **مركز إعدادات النظام:** بيانات الشركة، أنواع الإجازات واستحقاقاتها القابلة للتحديد، ترتيب الموافقات، أسماء الأدوار وصلاحياتها، وحقول الموظف الإضافية. إدارة الإعدادات لمدير النظام، وتُسجل التغييرات في سجل التدقيق. صلاحيات مدير النظام الأساسية ثابتة.
- **حقول الموظف الإضافية:** تُعرّف من الإعدادات وتظهر في نموذج الإضافة وتُخزن مع سجل الموظف؛ التحقق من القيم يجري في الخادم.
- **الإجازات:** تقديم طلبات الأيام أو الساعات، منع تداخل الفترات، مسار موافقات متعدد الخطوات، إلغاء الطلبات، أرصدة قابلة للتعديل عبر دفتر حركات غير قابل للاستبدال، وسجل تدقيق. تُقيّد طلبات مديري الفروع بموظفي فروعهم.

يُنشأ أول حساب مدير مرة واحدة من متغيرات البيئة عند تشغيل الخادم لأول مرة. إدارة الحسابات الإضافية تتطلب صلاحية إدارة المستخدمين؛ منح هذه الصلاحية لا يسمح بإنشاء أو ترقية حساب إلى مدير نظام.

**حدود سياسة الإجازات:** لا تُنشأ أنواع إجازة أو أرصدة قانونية افتراضية. تُحتسب أرصدة النظام من دفتر الحركات اليدوية، وحقول الاستحقاق السنوي وحد الترحيل تعريفات إرشادية وليست محرك استحقاق آلياً. يجب إدخال الرصيد الافتتاحي واعتماد أيام العمل والعطل والحصص وخطوات الموافقة قبل التشغيل. تتضمن ملفات Excel اختلافات تحتاج اعتماداً إدارياً وقانونياً: 21 يوماً سنوياً في معادلة مقابل شرائح خدمة أعلى، و15 يوماً مرضياً في إعداد الرواتب مقابل 30 يوماً و180 يوماً تراكمياً في ملاحظة قانونية. لا تعتمد هذه القيم كسياسة نافذة قبل حسمها.

## التطوير

```powershell
Copy-Item .env.example .env
docker compose up -d database
```

يتطلب تشغيل خدمات التطوير محلياً Node.js 22+ وPostgreSQL. أنشئ `backend/.env` باستخدام الإعدادات المحلية، ثم شغّل `npm install` و`npm run dev` داخل `backend`، وشغّل `npm install` و`npm run dev` داخل `frontend`. واجهة Vite تمرر `/api` إلى المنفذ 5000.

## البيانات المرفقة

نماذج Excel والعقود وملفات HTML المرفقة استُخدمت كمرجع للمجالات واللغة والواجهة فقط. لم تُنسخ بيانات الموظفين أو الرواتب إلى قاعدة البيانات. دليل الاستيراد يوضح نطاق المرحلة الحالية والخطوة التالية.
